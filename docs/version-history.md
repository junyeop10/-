## 파일 형식별 읽기 방식

- `txt`
  - `src/file_reader.py`에서 직접 읽습니다.
  - 인코딩은 `utf-8`을 먼저 시도하고, 실패하면 `cp949`로 다시 읽습니다.
  - 읽은 뒤에는 `build_sampled_text(...)`로 앞/중간/뒤를 샘플링해서 분류 근거 텍스트로 사용합니다.

- `pdf`
  - `src/pdf_reader.py`에서 `PyMuPDF(fitz)`를 사용해 텍스트 레이어를 추출합니다.
  - fast mode에서는 모든 페이지를 읽지 않고 앞/중간/뒤 구간에서 일부 페이지만 골라 읽습니다.
  - 일반 모드에서는 전체 페이지를 읽을 수 있습니다.
  - 텍스트 추출 결과가 비어 있거나 너무 짧으면 OCR fallback 대상으로 넘깁니다.

- `docx`
  - `src/office_reader.py`에서 `python-docx`를 사용합니다.
  - 문단 텍스트를 먼저 읽고, 표가 있으면 표 셀 텍스트도 함께 읽습니다.
  - 문단과 표 내용을 합쳐 분류 근거 텍스트로 사용합니다.

- `xlsx`
  - `src/office_reader.py`에서 `openpyxl`을 사용합니다.
  - 시트 이름을 읽고, 각 시트의 상단 행 데이터를 읽습니다.
  - fast mode에서는 기본적으로 상위 20행, 일반 모드에서는 더 많은 행을 읽습니다.
  - 표 전체를 다 읽는 방식이 아니라 시트명과 상단 구조를 중심으로 읽습니다.

- `pptx`
  - `src/office_reader.py`에서 `python-pptx`를 사용합니다.
  - 슬라이드 번호를 기록하고, 각 슬라이드 안의 shape 텍스트를 추출합니다.
  - 발표자료에서 실제 보이는 제목, 본문, 도형 텍스트를 근거 텍스트로 모읍니다.

## OCR fallback 방식

- OCR은 모든 PDF에 적용하지 않습니다.
- 먼저 일반 PDF 텍스트 추출을 시도한 뒤, `src/ocr_support.py`의 `should_run_ocr(...)` 조건을 통과한 경우에만 실행합니다.
- OCR 대상은 다음 기준으로 판단합니다.
  - PDF 파일인지
  - 파일명만으로 확실히 분류 가능한지
  - 일반 텍스트 추출 결과가 비어 있거나 너무 짧은지
- OCR이 실행되면 `PyMuPDF`로 PDF 페이지를 이미지로 렌더링한 뒤 `RapidOCR`로 글자를 인식합니다.
- 스캔 비용을 줄이기 위해 최대 5페이지까지만 OCR을 수행합니다.
- OCR 사용 여부는 분류 근거와 GUI 결과표에 함께 남깁니다.

## 사용 라이브러리와 모델

- 규칙 기반 분류
  - 학습 모델이 아니라 `data/categories.json`의 카테고리/키워드와 `src/rule_classifier.py`의 문맥 룰을 사용합니다.

- 임베딩 모델
  - `sentence-transformers` 기반 다국어 임베딩 모델을 사용합니다.
  - 현재 사용 모델은 `paraphrase-multilingual-MiniLM-L12-v2`입니다.
  - 문서 근거 텍스트와 카테고리 예시 텍스트를 벡터화해 유사도를 계산합니다.

- 로컬 LLM
  - `Ollama`를 통해 로컬에서 `qwen2.5:3b`를 호출합니다.
  - confidence가 애매한 문서에서만 보조 판단기로 사용합니다.
  - 입력으로 `evidence_text`, `category_scores`, `matched_keywords`를 전달하고, 출력은 JSON만 받습니다.

- OCR 엔진
  - `rapidocr_onnxruntime`를 사용합니다.
  - 프로세스마다 1회만 초기화되도록 lazy singleton 구조로 재사용합니다.

- 파일 형식별 추출 라이브러리
  - PDF: `PyMuPDF`
  - Word: `python-docx`
  - Excel: `openpyxl`
  - PowerPoint: `python-pptx`
